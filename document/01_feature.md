# 기능 명세

## 서비스 개요

대덕소프트웨어마이스터고 국외현장체험학습 일정 안내 웹앱.
`data.json`을 파싱하여 7일간의 일정을 모바일 친화적으로 시각화한다.

---

## 데이터 구조 (`data.json`)

```ts
interface Event {
  time: string;       // 예: "09:00", "오전", "" (빈 문자열 허용)
  title: string;
  location?: string;
  note?: string;
}

interface DaySchedule {
  day: number;        // 1 ~ 7
  date: string;       // 예: "5/11"
  weekday: string;    // 예: "일"
  region: string[];   // 예: ["대전", "인천", "SF"]
  hotel?: string;     // 마지막 날 등 숙소 없는 경우 생략
  events: Event[];
}
```

## 화면 구성

### 1. 전체 일정 목록 화면 (메인)

- 날짜별 카드 목록을 세로로 나열
- 각 카드에 표시할 정보:
  - Day N 뱃지 (예: `Day 1`)
  - 날짜 + 요일 (예: `5/11 일`)
  - 지역 태그 (예: `대전` `인천` `SF`)
  - 대표 이벤트 1~2개 미리보기 (첫 번째, 마지막 일정)
- 카드 탭 → 상세 화면으로 이동

### 2. 일별 상세 화면

- 상단: Day N / 날짜 / 요일 / 지역 태그
- 숙소 정보 (hotel 필드가 있을 경우 표시)
- 타임라인 형태의 이벤트 목록:
  - 시간 (time)
  - 일정 제목 (title)
  - 장소 (location, 있을 경우)
  - 참고 사항 (note, 있을 경우 보조 텍스트로 표시)
- 뒤로가기 버튼으로 목록 복귀

### 3. 오늘 일정 강조

- 현재 날짜가 일정 기간(5/11 ~ 5/17) 내에 해당하면 해당 Day 카드를 자동으로 강조 표시
- 기간 외에는 강조 없이 전체 목록만 표시

## 기능 요구사항

| ID | 기능 | 설명 |
|----|------|------|
| F-01 | 일정 데이터 로드 | 앱 초기화 시 `data.json` fetch 및 파싱 |
| F-02 | 전체 일정 목록 표시 | Day 1 ~ Day 7 카드 목록 렌더링 |
| F-03 | 일별 상세 보기 | 카드 클릭 시 해당 Day의 전체 이벤트 표시 |
| F-04 | 타임라인 렌더링 | 시간 순서대로 이벤트를 타임라인 UI로 표시 |
| F-05 | 오늘 일정 강조 | 현재 날짜와 일치하는 Day 카드 하이라이트 |
| F-06 | 숙소 정보 표시 | hotel 필드 존재 시 상세 화면 상단에 숙소명 표시 |
| F-07 | 지역 태그 표시 | region 배열을 칩(Chip) 형태로 렌더링 |
| F-08 | 빈 time 처리 | time이 빈 문자열이면 시간 영역을 숨김 처리 |

## 비기능 요구사항

### 모바일 최적화

- 기준 뷰포트: 360px ~ 430px (모바일 세로)
- 터치 친화적 탭 영역: 최소 44px 높이
- 스크롤은 세로 단방향, 가로 스크롤 없음
- 카드 간격 및 폰트 크기는 모바일 가독성 기준으로 설정

### 접근성

- 시맨틱 HTML 사용 (`<main>`, `<section>`, `<time>`, `<ul>` 등)
- 이미지 없이 텍스트와 아이콘만으로 구성하여 로딩 속도 최소화

### 성능

- 외부 API 호출 없음, 로컬 `data.json` 단일 파일 파싱
- 초기 로딩 시 전체 데이터를 한 번만 fetch

## 예외 처리

| 상황 | 처리 방법 |
|------|-----------|
| `data.json` 로드 실패 | 에러 메시지 표시 ("일정을 불러올 수 없습니다") |
| `time` 빈 문자열 | 시간 표시 생략, 제목만 표시 |
| `hotel` 미존재 | 숙소 영역 자체를 렌더링하지 않음 |
| 일정 기간 외 날짜 | 오늘 강조 없이 전체 목록 표시 |
